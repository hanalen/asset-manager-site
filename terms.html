이용약관

운영자: hanalen · 시행일: 2026년 9월 8일

이 약관은 Asset Manager의 현재 개발 버전에 적용됩니다.

1. 앱의 목적

Asset Manager는 사용자가 보유한 로컬 창작 에셋을 검색·미리보기·정리하고 프로젝트로 복사하며 관리 정보를 백업하는 도구입니다. Google Drive 연동은 선택 기능입니다.

2. 에셋의 권리와 이용조건

에셋의 저작권과 이용 권한은 해당 권리자와 라이선스에 따릅니다. 앱에 파일을 등록하거나 라이선스 확인 상태를 변경해도 사용 권한이 생기지 않습니다. 사용자는 에셋의 실제 약관과 허용 범위를 확인해야 합니다. 모델 내부에 기록된 이용조건은 참고 정보로 표시하며 법적 판단을 대신하지 않습니다.

3. 저장과 백업

원본 에셋과 실제 증빙 파일은 새 DB 백업에 포함되지 않습니다. 사용자는 필요한 원본과 증빙을 별도로 보관해야 합니다. 자동 백업을 켜면 안내된 보관 정책에 따라 오래된 자동 백업이 Drive 휴지통으로 이동할 수 있습니다.

4. 개발 버전과 외부 서비스

지원 형식, 미리보기 품질과 기능은 변경될 수 있습니다. 제작 프로그램 고유 기능이나 모든 파일의 호환성을 보장하지 않습니다. Drive 연결은 Google 서비스의 이용 가능 상태·권한·저장 공간에 영향을 받습니다. 장애나 데이터 문제는 문의 창구로 알려 주세요.

5. 비용과 변경

현재 공개 판매·구독 조건은 정해지지 않았습니다. 향후 유료 제공 시 가격과 적용 조건을 별도로 안내합니다. 이 초안은 결제나 구독 신청을 받지 않습니다. 관련 법령에 따라 보장되는 이용자의 권리를 제한하지 않습니다.

6. 문의

GitHub Issues로 문의해 주세요. 데이터 처리 내용은 개인정보처리방침에서 확인하실 수 있습니다.
