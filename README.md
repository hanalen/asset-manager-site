# Asset Manager 공개 페이지

앱 코드와 분리된 소개·정책 페이지 저장소입니다. 문서는 현재 구현 기준의 검토용 초안입니다.

- `index.html`: 앱 소개
- `privacy.html`: 개인정보처리방침
- `terms.html`: 이용약관
- 문의: https://github.com/hanalen/asset-manager-site/issues

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

공개 전 확인: 정책 내용·운영자·시행일 확정, Google Search Console에서 사이트 소유권 확인 가능 여부 검증(필요 시 보유 도메인 연결), OAuth 브랜딩 URL 등록, 게시와 로그인 검증. 기본 github.io 주소만으로 Google 인증 요건 충족을 보장하지 않습니다.

OAuth JSON·토큰·사용자 DB·증빙·앱 소스는 이 저장소에 넣지 않습니다. 별도 빌드나 외부 스크립트 없이 정적 HTML/CSS로 제공합니다.
