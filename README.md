# Asset Manager 공개 페이지

앱 코드와 분리된 소개·정책 페이지 저장소입니다. 문서는 현재 개발 버전을 기준으로 작성했습니다.

- `index.html`: 앱 소개
- `privacy.html`: 개인정보처리방침
- `terms.html`: 이용약관
- 문의: https://github.com/hanalen/asset-manager-site/issues

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

공개 주소: https://hanalen.github.io/asset-manager-site/

Google 사이트 소유권 확인용 메타태그는 유지합니다. 사이트 배포와 Google OAuth 심사·승인은 별도 절차입니다.

OAuth JSON·토큰·사용자 DB·증빙·앱 소스는 이 저장소에 넣지 않습니다. 별도 빌드나 외부 스크립트 없이 정적 HTML/CSS로 제공합니다.
